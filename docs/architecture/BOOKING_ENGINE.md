# Booking Engine Direction

## Existing foundation
Customers, bookings, booking items, participants, products, sessions, ticket types, tickets and rules already exist.

## Intended responsibilities
- Cart validation
- Capacity reservation
- Inventory handling
- Pricing
- Rule evaluation
- Payment preparation
- Booking confirmation
- Ticket issuance
- Reservation expiry

## Ice-skating rules to support
- Under 3 not permitted
- Ages 3–5 require Kanga Skating Aid
- Under 5 must be accompanied on ice by an adult
- Under 10 must wear a helmet
- Session capacity cannot be exceeded

These rules must be backend-enforced and ultimately configurable.
