# Production Checklist

## Security
- Rotate development credentials
- HTTPS
- Secret management
- Rate limiting
- Audit logging
- Formal role matrix
- Privacy review

## Reliability
- Backups and restore testing
- Monitoring and alerting
- Central logs
- Error tracking
- Load testing
- Scanner offline/retry strategy

## Quality
- Unit tests
- Integration tests
- End-to-end tests
- CI pipeline
- Migration checks
- API documentation
- Release process
