# Project Glacier

## The Operating System for Seasonal Attractions

Project Glacier is a SaaS platform designed to help event operators sell, operate, and improve temporary attractions.

## Vision

One platform to sell, operate, and improve attractions.

## Version

Sprint 1 - Foundation

## Core Modules

- Event Management
- Ticketing
- Rules Engine
- QR Entry
- Waivers
- Operations Centre
- Reporting

## Architecture

Project Glacier uses:

- Next.js
- React
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- Docker

## Status

Currently in active development.
